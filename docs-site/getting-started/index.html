Get started

One desktop builds everything: the memory pod, the gateway, the VM image, and the three APKs. This page gets that machine ready and lays out the build order. The operator's host is Arch / Garuda — adapt package names for your distro.

Podman only

The whole stack is rootless Podman + Quadlet. Never docker, docker compose, or a VM/SSH deploy. Where a command below says podman, it means Podman.

Container + VM-image tooling

bash · arch/garuda
sudo pacman -S --needed podman qemu-user-static qemu-user-static-binfmt \
                        avahi nss-mdns openssl qrencode
sudo systemctl enable --now systemd-binfmt.service   # arm64 binfmt on Arch
sudo systemctl enable --now avahi-daemon.service      # mDNS advertisement

# Verify arm64 emulation for the rootfs build
podman run --rm --platform=linux/arm64 docker.io/alpine:3.23 uname -m   # → aarch64

Android build host

bash
sudo pacman -S --needed jdk17-openjdk android-tools
export ANDROID_HOME="$HOME/Android/Sdk"
# sdkmanager: platform 35, build-tools 35.0.0, platform-tools, NDK (for Podroid)
adb devices   # one arm64 device, e.g. UBV7N19122000968  device

GPU passthrough (NVIDIA CDI)

The stack is GPU-first: embedding, recall, ColBERT and DAE all run on GPU, and on a GPU host the installer rewrites pod images :latest → :gpu. Generate the CDI device so rootless Podman can pass the GPU through.

bash
sudo nvidia-ctk cdi generate --output=/etc/cdi/nvidia.yaml
podman run --rm --device nvidia.com/gpu=all docker.io/nvidia/cuda:12-base nvidia-smi

Build order

Build bottom-up — each layer depends on the one below it being live.

#LayerPage
1Memory pod up on the desktop (:8765)The memory pod
2PRO gateway provisioned + running (:8443, mDNS)The PRO gateway
3Podroid rootfs squashfs + APK built and installedPodroid — the VM
4hermes-agent boots in the VM, per-install key generatedhermes-agent & the key
5The three signed apps installedThe three apps
6Pair, wire, and verify end-to-endPairing & verify
Two Podroid variants exist — use the AVF one

The verified, shipping variant is the AVF/pKVM Podroid (a full Alpine squashfs VM). An older proot-based thin app also exists in the tree; these docs describe the AVF variant only.
