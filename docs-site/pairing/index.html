Pairing, wiring & verify

Everything is built; now connect it. This is the "PRO federation" moment — installing Mazemaker and pairing is what unlocks full federation into the desktop graph.

Pair & wire

With the pod + gateway up on the desktop:

  1. Podroid → boot the VM. Open the terminal, cat /opt/hermes/api_server.key.
  2. Mazemaker → Settings → ON-DEVICE POD KEY → paste the key → SAVE KEY → "● pod unlocked".
  3. Mazemaker → Settings → Secure Gateway → paste the base64 pairing code (or SCAN QR) → PAIR.
    • App finds the gateway via mDNS _mazemaker-gw._tcp, fetches its cert, verifies sha256(SPKI) == fp, pins it, stores the token.
    • Success: ● ENCRYPTED — TLS + token + AES via gateway, ● Paired with <ip>:8443, POD CONNECTION auto-filled.
  4. On pairing, gatewayClient != null → LocalPodMcpProxy binds the AVF TAP :8790 (MzkMcpProxy: MCP proxy listening on 10.198.95.x:8790 (guest-only)).
  5. Inside the guest, the podroid-hermes-mcp watcher resolves the default gateway, writes mcp_servers.mazemaker = http://<gw>:8790/mcp, and restarts podroid-hermes when the proxy is reachable but hermes has 0 tools — loading the 31 mazemaker tools.
The recall path is now live

guest hermes → app :8790 → gateway :8443 (cmd:pod /mcp) → pod :8765 → mazemaker graph. No hardcoded IP anywhere in the chain; the per-install key gates the local hop, the pinned cert + token gate the LAN hop.

End-to-end verify (release)

The acceptance test — everything on release builds.

bash · desktop
# 1. pod + gateway healthy
curl -s -H 'Accept: application/json' http://127.0.0.1:8765/mcp \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' >/dev/null && echo POD_OK
ss -tlnp | grep :8443 | grep -q 'LISTEN 0' && echo GATEWAY_OK

On the phone, with the VM booted, Mazemaker [POD·ON], pod unlocked and paired — open the Hermes tab and send:

The prompt

"Nutze dein mazemaker_recall Tool. Suche ColBERT dedup und gib mir memory-id plus Inhalt."

Pass criteria: hermes replies with real graph content in mazemaker's id + similarity format. Verified run: top hit id=955714 @ 0.5624, plus 955710/955709 and real commit SHAs. Confirm it isn't hallucinated:

mcp · desktop
mazemaker_get(memory_id=955714)   # → found:true, the 2026-07-08 ColBERT-dedup memory

If mazemaker_get returns found:true and the content matches, the whole chain — release VM → app proxy → encrypted gateway → pod → graph — is proven.
